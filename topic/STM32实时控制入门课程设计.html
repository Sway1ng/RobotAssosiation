STM32 实时控制入门：从点灯到智能小车

一、课程概述

1. 课程定位

本课程以一辆基础循迹小车为最终项目，带领初学者完成一次完整的机器人控制实践：

认识电子元件 → STM32 读取输入 → 程序进行判断 → 控制电机运动 → 根据结果不断调整

课程不追求全面讲解 STM32 的所有外设，而是围绕 GPIO、PWM、串口和传感器等最有代表性的内容，帮助参与者建立嵌入式机器人控制的基本认识。

2. 面向对象

课程面向：

  • 对机器人、嵌入式或电子制作感兴趣的本科生；
  • 具有基础 C 语言知识、但没有 STM32 开发经验的同学；
  • 接触过 Arduino、希望进一步了解底层控制的同学。

不要求参与者具备电路、控制理论或单片机基础。课程从最基本的电子元件和接线开始，但只讲与项目直接相关的内容。

建议每组 2～3 人，并尽量将不同基础的同学混合分组。

3. 建议课时

  • 共 4 次课；
  • 每次 2～2.5 小时；
  • 总时长约 9 小时。

二、课程目标

完成课程后，参与者能够：

  1. 认识电阻、LED、按键、电容、电机和电机驱动模块等基本元件；
  2. 理解电压、电流、限流、供电和共地等基本概念；
  3. 理解 GPIO、PWM、串口和传感器的基本作用；
  4. 完成 STM32 程序的编译、下载和基本调试；
  5. 使用 GPIO 控制 LED、读取按键和数字传感器；
  6. 使用 PWM 调节 LED 亮度和电机速度；
  7. 使用串口输出传感器数据和运行状态；
  8. 编写简单的循迹控制程序；
  9. 理解机器人控制中“输入—处理—输出—反馈”的基本流程；
  10. 掌握先测试单个模块、再进行系统集成的基本调试方法。

三、课程最终项目

每组完成一辆能够在简单赛道上运行的基础智能小车，至少具备以下功能：

  • LED 状态提示；
  • 按键启动和停止；
  • 两个直流电机独立控制；
  • 通过 PWM 调节电机速度；
  • 红外传感器检测黑线；
  • 根据传感器信息调整运动方向；
  • 通过串口输出传感器状态和调试数据。

课程评价重点不在于单纯比较小车速度，而在于参与者能否：

  • 说明各硬件模块的作用；
  • 解释程序与硬件之间的对应关系；
  • 根据现象定位问题；
  • 通过调整参数或修改代码改进运行效果。

四、核心知识内容

1. 基本电子元件

结合项目介绍与实践直接相关的元件：

  • 电阻：限流、上拉和下拉；
  • LED：正负极识别，以及为什么需要串联限流电阻；
  • 按键：输入信号、上拉/下拉和按键抖动；
  • 电容：滤波和储能，理解电机启动对电源稳定性的影响；
  • 二极管、三极管：只介绍单向导电和开关作用，帮助理解驱动与保护电路；
  • 直流电机：基本特性、供电需求和方向控制；
  • 电机驱动模块：为什么 STM32 不能直接驱动电机，以及驱动模块如何提供较大电流。

电子基础部分不追求复杂的电路计算，重点是让参与者知道元件“是什么、有什么作用、如何连接、接错可能造成什么现象”。

2. STM32 基础外设

  • GPIO：控制 LED、读取按键和数字传感器；
  • 定时器与 PWM：调节 LED 亮度和电机速度；
  • 串口：输出传感器数据和运行状态，辅助调试；
  • 工程开发流程：创建或打开工程、编译、下载、复位和观察现象。

3. 传感器与控制

  • 红外循迹传感器的基本工作方式；
  • 数字传感器与模拟传感器的区别；
  • 传感器安装高度、地面材质和光照对读数的影响；
  • 根据传感器状态判断小车偏差；
  • 通过改变左右电机速度实现方向修正；
  • 误差、反馈和比例控制的直观理解。

五、课时安排

第一次课：基本电子元件与 STM32 点灯

核心内容

  • 电压、电流、电阻的直观概念；
  • 电阻、LED、按键、电容等元件的作用；
  • 面包板、杜邦线和基本接线方法；
  • STM32 开发板与 GPIO 输入输出；
  • 工程编译、下载和运行的基本流程。

实践任务

  1. 正确连接 LED 和限流电阻；
  2. 完成 LED 闪烁；
  3. 使用按键控制 LED；
  4. 观察按键抖动，并进行简单处理。

本次课要建立的认识

STM32 可以读取外部状态，也可以输出控制信号。LED 和按键是理解“输入与输出”的最简单例子。

第二次课：PWM 与电机控制

核心内容

  • 定时器和 PWM 的基本概念；
  • 周期、频率和占空比的直观含义；
  • 占空比对 LED 亮度和电机速度的影响；
  • 直流电机和电机驱动模块；
  • 电源、共地和电机干扰问题。

实践任务

  1. 使用 PWM 改变 LED 亮度；
  2. 控制一个电机正转、反转和停止；
  3. 控制两个电机使小车前进、后退和转向；
  4. 通过按键切换不同速度档位。

本次课要建立的认识

STM32 通常不直接驱动电机，而是输出控制信号，由电机驱动模块提供足够的电流。PWM 是控制执行器的重要方法。

第三次课：传感器与基础循迹

核心内容

  • 红外循迹传感器的工作原理；
  • 数字传感器和模拟传感器的区别；
  • GPIO 读取传感器；
  • 串口输出传感器状态；
  • 根据传感器状态判断小车偏差和运动方向。

实践任务

  1. 读取左、中、右三个红外传感器；
  2. 通过串口观察传感器数据；
  3. 编写“左偏右转、右偏左转”的控制逻辑；
  4. 让小车在简单直线赛道上完成基础循迹。

本次课要建立的认识

循迹的本质是：

传感器发现偏差，STM32 进行判断，电机改变速度和方向。

第四次课：综合调试与项目展示

核心内容

  • 小车各模块的整合；
  • 传感器位置和电机速度校准；
  • 常见故障排查；
  • 误差、反馈和比例控制的基本概念；
  • 如何记录调试过程并表达项目思路。

实践任务

  1. 完成完整循迹；
  2. 调整基础速度和转向修正强度；
  3. 记录至少一次“现象—推测—修改—验证”的调试过程；
  4. 介绍本组小车的硬件结构和程序逻辑。

本次课要建立的认识

机器人项目通常不是一次写对，而是通过观察现象、提出原因、修改参数或代码、再次测试，逐步达到稳定运行。

六、教学设计思路

1. 先现象，后原理

先让参与者看到 LED 亮度、电机速度和传感器数据的变化，再解释 GPIO、PWM 和传感器的原理，降低抽象概念的理解难度。

2. 先单模块，后系统整合

依次验证 LED、按键、电机和传感器，最后再调试整辆小车。这样可以避免多个问题同时出现，方便初学者定位故障。

3. 基础任务与提高任务分开

基础任务保证所有参与者能够完成点灯、电机控制和规则循迹。有经验的同学可以进一步尝试比例控制、避障或蓝牙遥控，但拓展内容不影响基础课程完成。

4. 提供框架，保留思考

教师提供工程模板、模块接口、接线图和关键代码框架，让参与者补充传感器判断和电机控制等核心逻辑，降低入门难度，同时避免直接复制最终答案。

5. 设置阶段性检查点

每完成一个模块就进行简单检查：

  • LED 是否能正常控制；
  • 按键状态是否能稳定读取；
  • 电机是否能够调速和换向；
  • 串口数据是否合理；
  • 小车是否能够根据传感器改变方向。

七、软硬件条件

1. 每组硬件

  • STM32F103 开发板 1 块；
  • ST-LINK 或其他下载器 1 个；
  • 两轮或四轮小车底盘 1 套；
  • 直流减速电机 2 个；
  • 电机驱动模块 1 个；
  • 三路或五路红外循迹模块；
  • LED、电阻、按键、电容若干；
  • 面包板或小型扩展板；
  • 杜邦线；
  • 电池盒、电池和 USB 数据线。

2. 软件

  • STM32CubeMX；
  • STM32CubeIDE 或 Keil；
  • ST-LINK 驱动；
  • 串口调试工具；
  • 课程配套工程模板、接线图和实验指导材料。

3. 课前准备

为节省课堂时间，建议提前完成：

  • 开发环境安装与测试；
  • 小车底盘安装；
  • 示例工程准备；
  • 演示小车调试；
  • 备用开发板、驱动模块、电机和电池准备。

八、实施中的问题与解决办法

1. 参与者基础差异较大

采用分组合作和分层任务。基础薄弱的同学完成必做功能，基础较好的同学承担提高任务或协助调试。

2. 电子元件和线路容易接错

提供实物照片、清晰接线图和通电前检查表。要求先断电检查，再连接电源。

3. 电机造成开发板重启

规范电机供电，必要时将电机与开发板分开供电，并确保两部分共地。准备备用电池和驱动模块。

4. 传感器数据不稳定

先通过串口观察原始数据，再调整传感器高度、灵敏度和安装位置，同时尽量统一赛道材料和光照条件。

5. 课时内无法完成所有功能

提前完成底盘安装和环境配置。基础目标只要求完成规则循迹，比例控制、避障和蓝牙控制作为课后拓展方向。

6. 硬件性能存在差异

评价重点放在功能完成、问题分析和调试过程，不单纯按照小车速度排名。必要时提供统一的基础参数和测试赛道。

九、课程成果与评价

预期成果

每组完成：

  • 一辆基础循迹小车；
  • 一份简单的模块连接图；
  • 一份可运行的 STM32 工程；
  • 一张调试记录表；
  • 一次简短项目展示。

评价建议

评价内容 比例
基本电子元件与接线理解 20%
STM32 基础功能完成 25%
小车循迹功能 30%
调试记录与问题分析 15%
小组展示与协作 10%

评价重点是教学目标是否达成，以及参与者能否解释和改进自己的作品。

十、课程核心价值

这门课希望参与者掌握的不是若干个 STM32 函数，而是机器人控制的基本思路：

用传感器获取环境信息，用 STM32 进行处理，再通过电机执行动作，并根据反馈持续修正。

从点灯开始，最后完成智能小车，参与者能够直观理解电子元件、嵌入式程序和机器人运动之间的联系，并为后续学习 STM32、嵌入式系统和机器人控制打下基础。
