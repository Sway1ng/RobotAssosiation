# 《PWM 与电机控制》授课型幻灯片 Demo 大纲

## 选题与定位

**选题：**第二次课“PWM 与电机控制”

**预计授课时间：**约 10 分钟，建议 8 页，包含 1 页封面和 7 页正文。

**听众：**会使用 Arduino 完成简单 GPIO 实验，但第一次接触 PWM 和电机控制的初学者。

**本次课要回答的问题：**Arduino 如何用高低电平信号控制 LED 亮度和小车电机速度？

**听众应带走的结论：**

> PWM 不是输出一个固定的“中间电压”，而是在固定周期内快速开关，通过改变高电平所占的时间比例，改变负载感受到的平均效果。

课程重点放在占空比、频率、Arduino 编程和电机驱动之间的关系，不展开定时器寄存器或完整 PID 推导。

---

## 讲解主线

1. 先展示两个亮度不同的 LED 和两种速度的小车，引出“同一个电源，为什么效果不同”；
2. 用动画式方波解释 PWM 的占空比；
3. 进一步区分占空比与频率，说明它们分别影响什么；
4. 用 Arduino 的 `analogWrite()` 把波形参数落到代码；
5. 从 LED 过渡到电机，解释驱动模块、电源和方向控制；
6. 用一个可运行的小实验和一个故障排查例子收束。

### 1. PWM 的基本形状：快速开关

**预计时间：**1 分 20 秒

**页面核心句：**`PWM 用高低电平的快速切换，控制一个周期内的导通时间。`

**页面内容：**用逐帧或分步动画展示三个同周期方波：

```text
25%：▮▯▯▯    高电平时间短
50%：▮▮▯▯    高低电平各占一半
75%：▮▮▮▯    高电平时间长
```

配合波形标注：

- 周期 `T`：完成一次开关循环的时间；
- `T_on`：高电平持续时间；
- 占空比 `D = T_on / T`。

**图示建议：**用三条横向波形，统一周期和电压高度，只改变高电平宽度。高电平用橙色，低电平用灰色。

**互动：**出现 25%、50%、75% 三个波形后，先问“哪一个 LED 最亮？”，再显示答案。

### 2. PWM 的理论：占空比、频率和平均效果

**预计时间：**1 分 40 秒

**页面核心句：**`占空比决定“每周期通电多久”，频率决定“开关有多快”。`

**页面内容：**

#### 占空比

对电源电压为 `Vcc` 的理想负载，可以用平均值直观理解：

```text
V_avg ≈ D × Vcc
```

例如 5 V 电源下，50% 占空比对应约 2.5 V 的平均效果。这里的“平均”是负载在一段时间内感受到的结果，PWM 引脚本身仍然只输出 0 V 或 5 V。

#### 频率

- 频率太低：LED 可能闪烁，电机可能抖动或发出明显噪声；
- 频率足够高：LED 看起来稳定，电机利用自身惯性平滑运动；
- 频率不是越高越好，还要考虑驱动器开关损耗和电机特性。

**图文设计：**左侧放三组占空比波形，右侧放“低频闪烁—合适频率—过高损耗”的简图。不要把“速度与占空比严格线性”作为结论，标注负载、摩擦和电池电量会改变实际结果。

### 3. Arduino 里的 PWM：`analogWrite()` 到底做了什么？

**预计时间：**1 分 20 秒

**页面内容：**展示一个最小可运行例程：

```cpp
const int ledPin = 9;  // Arduino UNO 的 PWM 引脚

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 128);  // 约 50% 占空比
  delay(1000);
  analogWrite(ledPin, 32);   // 约 12.5% 占空比
  delay(1000);
}
```

旁边配一个映射图：

```text
analogWrite(pin, value)
value = 0   → 0%   → 常灭
value = 128 → 约50% → 中等亮度
value = 255 → 100% → 常亮
```

**讲解重点：**Arduino Uno 的 `analogWrite()` 参数通常是 0～255；只有标有 `~` 的 PWM 引脚支持该功能。`analogWrite()` 名字容易让人误以为输出了真正的模拟电压，页面要明确它实际是在输出 PWM。

**互动：**让听众先预测 `value = 200` 的亮度，再运行代码验证。

### 4. 先用 LED 验证，再接入电机

**预计时间：**1 分钟

**页面内容：**用一个“实验台”画面并排呈现：

```text
Arduino PWM 引脚 → 限流电阻 → LED

Arduino PWM 引脚 → 电机驱动模块 → 直流电机
                         ↑
                    独立电机电源
```

底部用一句话区分两种负载：

- LED：现象直观，电流较小，适合验证占空比；
- 电机：需要较大电流，必须通过驱动模块。

**讲解重点：**Arduino 引脚负责“告诉驱动模块怎么做”，驱动模块负责提供电机需要的电流。电机电源、Arduino 地线和驱动模块地线要按模块要求连接，不能把电机直接接到 Arduino 引脚。

**图示建议：**用橙色细线表示 PWM 控制信号，用粗蓝线表示电机供电，让“信号”和“功率”在图上明显区分。

### 5. Arduino 控制电机：方向 + 速度

**预计时间：**1 分 30 秒

**页面内容：**给出简化的单电机控制代码：

```cpp
const int enA = 5;   // 接驱动器 PWM/EN
const int in1 = 7;   // 方向控制
const int in2 = 8;

void motorForward(int speed) {
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  analogWrite(enA, constrain(speed, 0, 255));
}

void setup() {
  pinMode(enA, OUTPUT);
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
}

void loop() {
  motorForward(80);   // 低速
  delay(1500);
  motorForward(200);  // 高速
  delay(1500);
}
```

**图文配合：**代码左侧用箭头标出：

1. `in1/in2` 决定正转或反转；
2. `enA` 接收 PWM，改变速度；
3. 驱动器把控制信号转换成电机端的功率输出。

**讲解重点：**`analogWrite()` 的数值只是控制量，实际速度还受电机负载、电池电量、地面摩擦和左右电机差异影响。

### 6. 一个小实验：占空比真的决定速度吗？

**预计时间：**1 分 20 秒

**页面内容：**设计一个现场可做的对比实验：

| 设置 | Arduino 参数 | 观察现象 |
|---|---:|---|
| 低速 | `analogWrite(enA, 80)` | 是否能稳定启动 |
| 中速 | `analogWrite(enA, 150)` | 转速和噪声如何变化 |
| 高速 | `analogWrite(enA, 220)` | 是否更快，是否更容易跑偏 |

用三张小车运动示意图或一条速度刻度条配合展示。旁边放两个问题：

- 为什么从 0 调到 30 时，电机可能仍然不转？
- 为什么左右电机设置相同数值，小车仍然可能向一侧偏？

**讲解重点：**电机存在启动所需的最小驱动力，左右电机的机械和电气特性也不会完全一致。因此，占空比是控制输入，不能直接等同于精确速度。

### 7. 故障排查：从波形和供电开始

**预计时间：**1 分 20 秒

**页面内容：**将排查画成一条带图标的流程：

```text
代码在运行吗？
      ↓
PWM 引脚是带 ~ 的引脚吗？
      ↓
驱动器有电、Arduino 与驱动器共地吗？
      ↓
方向引脚和电机接线正确吗？
      ↓
左右轮是否需要分别校准？
```

对应两个故障气泡：

- **完全不转：**先查电源、使能端、共地和接线；
- **一边快、一边慢：**先降低速度，再分别测量和校准左右轮。

**讲解重点：**先确认控制信号和供电链路，再调参数。故障排查页不放复杂公式，重点是让初学者有一条可执行的顺序。

### 8. 总结：PWM 的三个关键词

**预计时间：**30 秒

**页面只保留三组图文：**

- **占空比**：每个周期内，高电平持续多久；
- **频率**：开关循环进行得多快；
- **驱动器**：把 Arduino 的控制信号转换为电机需要的功率。

```text
Arduino 参数 → PWM 波形 → 电机驱动器 → 电机运动
```

## 画面与制作要求

- **一页只讲一个问题。** 理论页讲波形和频率，代码页讲 `analogWrite()`，实验页讲“相同电源下为什么表现不同”。
- **图文比例约为 6:4。** 波形、控制链和小车示意图占主要空间，文字用来标注关键概念。
- **让波形动起来。** Marp HTML 中可以用三组 SVG 波形逐页显示，或用同一位置的三张波形图模拟动画效果。
- **让听众先猜再看答案。** 在 LED 亮度、占空比和电机速度三个地方各设置一次预测问题。
- **颜色有明确含义。** 橙色表示 PWM 信号，蓝色表示电源和硬件，黄色表示 LED 或可见效果，红色只用于故障提示。
- **代码保持可运行。** 使用 Arduino Uno 常见写法，代码块只保留必要的 `pinMode()`、`digitalWrite()` 和 `analogWrite()`。
- **避免绝对化表述。** 页面中说明占空比通常会影响平均驱动力，但实际速度还受到负载、摩擦、电池和电机差异影响。
- **每页保留较大字号。** 标题至少 32pt，正文尽量不低于 20pt；一页最多保留 5～6 个信息点。
